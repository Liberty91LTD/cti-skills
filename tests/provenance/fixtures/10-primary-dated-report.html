Gateway pre-auth RCE: an analysis

We reverse-engineered the patched firmware and identified the root cause of the pre-authentication flaw in the request parser.

Static analysis of the two firmware versions shows the fix adds a bounds check that was previously missing from the handler.

The backdoor keeps a small footprint on disk and loads most of its functionality from the network at run time.

Network defenders can find indicators of compromise and detection guidance at the end of the published analysis.
