Placeholder domain now serves a fake verification page

A domain that has long been used in software documentation as a stand-in for an external site is now serving a fake verification page to visitors.

According to an analysis by Unit 42, the page asks visitors to paste a command into the Run box.

The command downloads a script from a second domain. We did not observe a ransom note or any claim posted on a leak site in connection with this activity.

We could not confirm how many visitors ran the command, and the second domain was not resolving at the time of writing.
