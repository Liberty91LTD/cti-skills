Introduction

We identified renewed exploitation of managed file transfer servers by a cluster we track as Harbour Lynx, observed in our telemetry across several sectors.

The operators changed one character in the request path, which allowed the request to pass filtering rules that matched the literal path only.

Post-exploitation activity

After gaining access the operators placed a web shell on the server and used it to run commands under the service account of the application.

We observed archive files being created in temporary directories shortly before outbound transfers to infrastructure controlled by the operators.

Attribution

We assess with moderate confidence that this activity is conducted by the same operators as the campaign we reported in June of this year.

The assessment rests on overlapping infrastructure and on the reuse of a distinctive file naming scheme seen in both periods of activity.

Remediation

Apply the vendor update and restrict administrative endpoints from the public internet, which does not affect ordinary user sessions.

Organisations that find a web shell should treat the host as compromised, preserve evidence and rotate every credential reachable from it.
